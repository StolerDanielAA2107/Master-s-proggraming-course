Лабораторная работа 1

Реализована на Python простейшая картотека в виде консольного приложения.

Приложение включает:
1. Классы, описывающие элементы картотеки (предок/потом[ок|ки] — студент/староста/профорг, служащий/управляющий/директор и т.п.), содержащие атрибуты, описывающие элемент (имя, возраст и т.п.), поле/поля с ссылкой/ссылками на реализацию ввода/вывода, а также функции, использующие эти реализации для ввода/вывода полей объекта.
2. Класс, реализующий интерфейсную стратегию ввода/вывода для работы с консолью, функции которого в качестве параметра получают ссылку на объект и имя запрашиваемого поля в случае вывода.
3. Контейнерный класс (группа, компания и т.п.), содержащий:
- контейнер (список либо словарь) элементов;
- функцию добавления элемента (с выбором типа объекта);
- функцию вывода списка на экран;
- функцию чтения списка из файла;
- функцию записи списка в файл;
- функцию очистки списка.
4. Класс, реализующий стратегию ввода/вывода для работы с хранилищем на основе модуля pickle либо shelve, используемый контейнерным классом.
5. Функцию main, выводящую и обрабатывающую текстовое меню, которое позволяет воспользоваться всеми функциями, экспортируемыми контейнерным классом.

Лабораторная работа 2
Преобразовано консольное приложение картотеки в WSGI-приложение, использующее фреймворк Flask.

Реализация:
- преобразована стратегия работы с хранилищем, перенеся в нее из контейнерного класса список/словарь элементов и реализовав интерфейс для работы с ними;
- переход от консольного ввода-вывода к вводу-выводу в браузер реализован с помощью добавления новой стратегии для работы с Flask.

Лабораторная работа 3
Преобразовано WSGI-приложение картотеки в клиента базы данных SQLite.
Реализация:
- учтены возможные изменения идентификатора своего модуля;
- предусмотрена возможность импорта информации, сохраненной первой лабораторной;
- использован механизм подстановки параметров DB-API;
- для хранения данных использован подкаталог data, для размещения шаблонов подкаталог app/templates и — app/static.
